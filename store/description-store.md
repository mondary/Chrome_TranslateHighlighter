## Description longue

### FR

**PK Traduction** traduit instantanément le texte sélectionné avec affichage en popup ou substitution directe. Sélectionnez du texte sur une page web : le popup s'affiche automatiquement en dessous.

#### ✨ Fonctionnalités clés
- **Traduction instantanée** — traduction du texte sélectionné à la volée
- **Mode substitution directe** — le texte sélectionné est remplacé par sa traduction
- **Traduction de page entière** — un clic sur l'icône traduit tout le contenu de la page active, par lots
- **Indicateur de chargement** — suivi en temps réel pendant la traduction
- **Interface épurée** — popup discret avec positionnement automatique
- **Réglages simples** — langue cible (défaut : français), mode de traduction automatique, option de substitution

### EN

**PK Traduction** instantly translates selected text with popup display or direct substitution. Select text on a webpage: the popup appears automatically right below it.

#### ✨ Key features
- **Instant translation** — selected text translated on the fly
- **Direct substitution mode** — the selected text is replaced by its translation
- **Full page translation** — one click on the icon translates all content of the active page, in batches
- **Loading indicator** — real-time feedback during translation
- **Minimalist interface** — discreet popup with automatic positioning
- **Simple settings** — target language (default: French), auto-translate mode, substitution option
