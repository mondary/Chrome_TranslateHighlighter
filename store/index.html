FAQ

Quelques choses à savoir.A few things worth knowing.

Que fait l'extension de mes données ?What happens to my data?

Rien n'est stocké ni partagé. Le texte sélectionné est envoyé à l'API de traduction de Google — comme le ferait la page elle-même — et la réponse s'affiche dans le popup. Aucun compte, aucune analyse d'usage, aucun envoi vers un serveur PK-Labs.Nothing is stored or shared. The selected text is sent to Google's translation API — as the page itself would — and the answer appears in the popup. No account, no usage analytics, nothing sent to a PK-Labs server.

Pourquoi la traduction est-elle parfois approximative ?Why is the translation sometimes approximate?

Comme toute traduction automatique : les argots, les subtilités et les cultureymes se perdent en route. Sélectionnez une phrase entière plutôt qu'un mot isolé, et la qualité remonte sensiblement.Like any machine translation: idioms, subtleties and culture-specific phrasing get lost along the way. Select a whole sentence rather than a single word and the quality improves noticeably.

Est-ce que ça fonctionne hors ligne ?Does it work offline?

Non. La traduction passe par l'API Google Translate : une connexion internet est nécessaire. L'extension n'envoie rien tant que vous n'avez pas sélectionné de texte.No. Translation goes through the Google Translate API, so an internet connection is required. The extension sends nothing until you select text.

Comment l'installer ?How do I install it?

Chrome 100 ou plus récent, via la fiche Chrome Web Store dès sa publication, ou en chargeant le dossier src depuis chrome://extensions en mode développeur.
