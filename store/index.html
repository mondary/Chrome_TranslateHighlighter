Installer PK TraductionInstall PK Traduction

Gratuit et open source, en quatre étapes.Free and open source, in four steps.

  1. Téléchargez ou clonez le dépôt GitHub.Download or clone the GitHub repository.
  2. Ouvrez chrome://extensions/ dans Chrome.Open chrome://extensions/ in Chrome.
  3. Activez le Mode développeur.Enable Developer mode.
  4. Cliquez sur Charger l'extension non empaquetée et sélectionnez le dossier /src.Click Load unpacked and select the /src folder.
